# Evidence

This directory is reserved for reviewed, sanitised evidence from personal lab exercises. No real directory exports, private network inventories, credentials, certificates, tokens, backup archives or employer screenshots belong here.

Recreate diagrams and screenshots using fictional identities and documentation-only addresses where possible. Label illustrative examples clearly. Do not claim a test passed until the actual result has been recorded in the validation register.

## Evidence templates and records

- [Backup and restore evidence template](backup-restore-evidence-template.md) — use for disposable or live-lab isolated recovery exercises. The template starts at **NOT RUN** and must not be changed to PASS without actual validation.
- Existing dated evidence files record only exercises that have been explicitly reviewed for publication.

For backup/recovery work, retain raw logs privately when they expose repository names, hostnames, snapshot metadata or infrastructure paths. Publish a sanitised summary rather than raw operational output.
